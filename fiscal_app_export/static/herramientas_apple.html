Antes de empezar.

Preguntas frecuentes sobre las herramientas.

¿Son gratuitas las herramientas?

Crear cuenta es gratis. Los informes y el asesoramiento tienen sus propias condiciones de acceso; el registro no implica que todos los servicios estén incluidos. Consulta también las condiciones de cada recurso antes de solicitarlo.

¿Necesito registrarme para empezar?

Para importar tus operaciones y preparar el informe FIFO necesitas una cuenta. Puedes consultar las guías del método FIFO, el Modelo 721 y los exchanges compatibles sin registrarte.

¿Qué método de cálculo utiliza el informe?

FIFO significa «First In, First Out». La Agencia Tributaria recoge este criterio para identificar las unidades transmitidas de una misma criptomoneda homogénea: se consideran transmitidas primero las adquiridas antes. Debes tener en cuenta el historial completo, también las compras de ejercicios anteriores, para determinar el coste de las unidades vendidas o permutadas.

¿El informe sustituye a un asesor fiscal?

No. El informe organiza los datos importados y los cálculos para facilitar su revisión. No constituye asesoramiento fiscal ni legal, no sustituye al modelo oficial de declaración y no implica homologación de la Agencia Tributaria. Las operaciones complejas y otras particularidades requieren la valoración de un profesional. Úsalo como documentación de apoyo, junto con los registros originales.

¿Qué documentación necesito para preparar el informe?

Reúne los CSV originales y el historial completo de operaciones de la misma criptomoneda, aunque esté repartido entre varios exchanges o monederos. Las compras de ejercicios anteriores pueden afectar al coste de una venta posterior. Comprueba también las transferencias entre cuentas propias para evitar duplicados. Consulta las instrucciones de exportación de cada exchange.
